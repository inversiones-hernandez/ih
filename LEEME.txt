USO FUERA DEL SITIO WEB
Si necesitas el logo para otras cosas (redes sociales, tarjetas de
presentación, documentos, WhatsApp Business), te recomendamos:

- Foto de perfil en redes sociales / WhatsApp Business:
  usa "icon-512.png" (fondo transparente) o pide una versión con
  fondo blanco sólido si la plataforma no soporta transparencia.

- Documentos impresos o membretes:
  usa "logo-transparent.png"; si necesitas mayor resolución para
  impresión grande, dímelo y genero una versión de mayor tamaño
  a partir del archivo original que subiste.

- Banner para publicaciones/redes:
  "og-image.png" ya tiene el formato horizontal listo para usar
  como portada o publicación compartible.
